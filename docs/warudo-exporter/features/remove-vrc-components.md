---
title: "Remove VRChat Components"
description: "This feature removes VRChat components from your avatar."
sidebar_position: 6
---

This feature allows you to remove all VRChat components (except the Avatar Descriptor) from your avatar.
Leaving them on your avatar doesn't really cause any issues, but unrecognized components can spam log files.

This feature comes with the following option(s):

### Keep Physbones & Colliders
This option allows you to keep VRC Physbones and VRC Physbone Colliders so that Warudo can convert them to Dynamic Bones at runtime. This allows you to have some automatically converted physics. Warudo's conversion is not always great tho, so it is recommended to setup your own Physics using [alternatives](https://docs.warudo.app/docs/modding/character-mod#third-party-components).
