---
title: "Lock Poiyomi Shader Materials"
description: "This locks all Poiyomi Materials allowing them to be exported."
sidebar_position: 2
---

This feature [locks](https://www.poiyomi.com/general/locking) all [Poiyomi Shader](https://www.poiyomi.com/) materials on the avatar before exporting. Without this, unless manually locked, Poiyomi Shader materials don't get included in the build for technical reasons explained in it's documentation.
