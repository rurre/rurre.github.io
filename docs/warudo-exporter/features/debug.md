This section contains the debug features of the tool.

### Run Test Build

This allows you build your avatar in the scene without exporting it to Warudo. Useful for testing things before commiting to a longer export.

This option is equivalent to Hai's Denormalized Exporter's `Do not export or build`

This also makes NDMF export the built test avatar files to the `Assets/ZZZ_GeneratedAssets` folder in your assets.

### Don't Run VRCFury

This allows you to skip running all VRCFury components.

### Keep Working Object in Scene

This allows you to keep your Character.prefab (in the case of character mod) in the scene after a build.

This option is equivalent to Hai's Denormalized Exporter's `Do not delete work objects`
